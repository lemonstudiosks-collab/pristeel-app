# Opportunities waiting/layout v2

- `Draft i përgatitur` is not a separate operator lane.
- A platform-prepared Gmail draft is represented as `Në pritje` in Opportunities, while the raw Gmail/delivery state remains a draft until human send.
- `Të gjitha` is shown once; selecting it clears a source filter as well.
- Source chips with zero visible opportunities are hidden so the source row fits without horizontal scrolling.
- `UNDP Kosovo` is retired from the active source UI and Home policy; historical records remain for audit.
- The waiting bridge does not own click events and does not send email or write business data.
