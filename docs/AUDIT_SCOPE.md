# PPPP System Audit Scope

The audit treats the platform as five coupled surfaces:

1. Application boot and navigation.
2. Project workspace and commercial/procurement workflow.
3. Gmail, document and project intake automation.
4. Finance, contacts, tenders and external integrations.
5. Local OCR / semantic AI and server-side scheduled automation.

A surface is not marked verified only because its file exists. Verification requires either executable regression coverage, CI/runtime health evidence, or an observed authenticated browser result.
